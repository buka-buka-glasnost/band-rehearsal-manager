# Band Rehearsal Manager - Frontend

Frontend za Band Rehearsal Manager, komunicira sa REST backendom.
Završni projekat iz predmeta Internet softverske arhitekture.

## Tehnologije
- Next.js / React
- Axios (HTTP pozivi ka backendu)

## Preduslovi
- Node.js (v18+)
- Pokrenut backend na http://localhost:8080

## Pokretanje
1. Instalirati zavisnosti:
   npm install
2. Pokrenuti razvojni server:
   npm run dev
3. Aplikacija je dostupna na http://localhost:3000
